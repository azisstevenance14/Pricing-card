Bootstrap 5 Pricing Card Component

A clean, modern, and responsive Pricing Card component built using HTML5 and Bootstrap 5.3. This component is designed to display membership plans or product pricing details clearly with an intuitive visual hierarchy.

🚀 Features

Responsive & Centered Layout: Centered vertically and horizontally across viewports.

Visual Hierarchy: Highlighted price using typography utilities (display-5, text-primary).

Feature List with Icons: Integrated Bootstrap Icons for feature checkmarks.

Clean Elevation: Styled with borderless cards, rounded corners, and soft box-shadows.

🛠️ Tech Stack & Concepts Used

HTML5: Semantic tags (body, div, ul, li, button, span).

Bootstrap 5.3:

Flexbox Utilities: d-flex, justify-content-center, align-items-center, vh-100.

Card Utilities: card, shadow, border-0, rounded-4.

Typography & Colors: display-5, fw-bold, text-primary, text-muted, fs-6.

Buttons & Spacing: btn, btn-primary, w-100, mb-*, p-*.

Bootstrap Icons: Vector icon integration for feature list checkmarks.
